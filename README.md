# Лабораторная работа «Ничего не падает»

Консольное приложение на Kotlin для чтения расписания, фильтрации занятий и вывода ошибок входных данных.

## Сборка и запуск

Требуются JDK 25 и Python 3.10+ для проверки примеров. Команды выполнять из корня проекта.

```bash
chmod +x gradlew
./gradlew test
./gradlew build :app:installDist
python3 tools/verify.py
```

Запуск команд после сборки:

```bash
./app/build/install/schedule/bin/schedule period --file samples/clean.txt --from 2026-09-28 --to 2027-05-13
./app/build/install/schedule/bin/schedule type --file samples/dirty.txt --type EXAM
./app/build/install/schedule/bin/schedule errors --file samples/dirty.txt
```

Коды завершения: `0` — все строки корректны; `1` — файл обработан, но есть ошибочные строки; `2` — неверные аргументы или ошибка чтения.

## Модель и выбор типов

`Session` — sealed-интерфейс с датой и темой. `Lecture`, `Practice`, `Exam` и `Cancelled` — обычные `class`, а не `data class`: так не создаётся автоматически `copy()`, а создание новых объектов проходит через конструкторы с проверками. `Cancelled` реализует только `Session`, поэтому у него нет свойств места и преподавателей.

`ActiveSession` — общий sealed-интерфейс для `Lecture`, `Practice` и `Exam`. Он содержит `location` и `teachers`, поэтому команды обрабатывают все активные занятия общей веткой `when`, без повторения трёх одинаковых веток. `Exam` требует минимум двух разных преподавателей, остальные активные занятия — минимум одного.

Конструкторы проверяют год `1..9999`, тему, место, имена преподавателей, управляющие и внешние пробельные символы. Некорректные значения приводят к `IllegalArgumentException`.

## Защита коллекций

Список преподавателей копируется в новый `ArrayList` и оборачивается в `Collections.unmodifiableList`. Поэтому изменение переданного списка не меняет занятие, а изменить список через публичное свойство нельзя. `all()` репозитория аналогично возвращает неизменяемый снимок, который не зависит от последующих изменений хранилища.

## Репозиторий и делегирование

`InMemorySessionRepository` хранит занятия в порядке добавления и допускает дубликаты. `AuditedSessionRepository` использует `SessionRepository by delegate`, передавая хранение внутреннему репозиторию и переопределяя методы добавления для журнала.

Переопределить только `add` недостаточно: вызов `addAll` делегируется как отдельный метод интерфейса и не обязан вызывать `add` обёртки. Поэтому `add` журналируется одним событием с количеством `1`, `addAll` — одним событием с размером списка, включая пустой список с количеством `0`. `all()` не журналируется. Событие записывается после успешного добавления.

## Попытки сломать модель

| Попытка | Ожидаемая защита |
|---|---|
| Создать занятие с пустой темой | Проверка конструктора: `IllegalArgumentException` |
| Указать год `0` или `10000` | Проверка даты в конструкторе |
| Создать активное занятие без преподавателей | Проверка минимального количества преподавателей |
| Создать `Exam` с одним преподавателем | Требование минимум двух преподавателей |
| Передать двух одинаковых преподавателей | Проверка уникальности имён |
| Изменить исходный `MutableList` после создания занятия | Защитная копия списка |
| Изменить список через `teachers` | Неизменяемая обёртка; изменение запрещено |
| Изменить снимок `all()` | Неизменяемый снимок, внутренний репозиторий не меняется |
| Обойти проверки через `copy()` | `copy()` отсутствует у обычных `class` |

## Ошибки парсера

Парсер возвращает структурированную причину отказа и номер строки; отдельная функция формирует английское сообщение. Проверки выполняются в порядке, указанном в задании: разделитель, количество полей, пустые поля, дата, тип, количество преподавателей экзамена, затем доменные ограничения.

Сообщения для дополнительных причин:

- `field "…" contains a control character in "…"` — управляющий символ;
- `field "…" has leading or trailing whitespace in "…"` — пробелы по краям;
- `type "CANCELLED" requires "…" to be "-", got "…"` — неверные поля отмены;
- `invalid location "…"` — недопустимое место;
- `invalid teacher "…"` — недопустимое имя преподавателя;
- `duplicate teacher "…"` — повтор имени преподавателя.

Основные сообщения: `invalid field separator`, `got N fields, expected 5`, `empty required field "…"`, `invalid date "…"`, `unknown session type "…"`, `type "EXAM" requires at least 2 teachers, got N`. Значения в сообщениях экранируются: обратная косая черта, кавычки, управляющие и не-ASCII символы.
